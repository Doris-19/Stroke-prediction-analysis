# Stroke Prediction Using Machine Learning

**Group 30 Capstone Project | Data Science**

## Project Overview
This project explores the use of data science and machine learning techniques to identify patterns associated with stroke occurrence using patient demographic and health-related data.

The project covers data cleaning, exploratory data analysis, feature engineering, clustering and classification.

## Objectives
- Explore factors associated with stroke occurrence.
- Clean and preprocess patient data.
- Perform exploratory data analysis.
- Apply K-Means clustering to identify patient segments.
- Develop and evaluate machine learning classification models.
- Address class imbalance and compare model performance.

## Dataset
Source: [Kaggle – Stroke Prediction Dataset](https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset)

- 5,110 patient records.
- 12 original columns.
- 249 stroke-positive cases.
- 4,861 stroke-negative cases.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib
- SQL and SQLite
- Scikit-learn
- Imbalanced-learn
- Google Colab

## Methodology
1. Data acquisition and SQL analysis.
2. Data cleaning and missing-value treatment.
3. Exploratory Data Analysis (EDA).
4. Feature engineering and encoding.
5. K-Means clustering.
6. Classification using Logistic Regression, Decision Tree and Random Forest.
7. Class imbalance handling using SMOTE, class weighting and threshold optimisation.
8. Model evaluation and interpretation.

## Key Findings
- Identified four patient clusters with different health characteristics.
- Age emerged as an influential feature in the classification analysis.
- Logistic Regression with an optimised classification threshold was selected as the final analytical candidate.
- Final model results: 86.69% accuracy, 58% recall, 20.14% precision and 0.8377 ROC AUC.

## Conclusion
The project demonstrates how data science and machine learning can be applied to healthcare data to explore stroke-related patterns and develop predictive models.

**Note:** This is an educational project and not a clinically validated diagnostic tool.
